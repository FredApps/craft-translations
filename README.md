# Craft translations

Data-only translation candidates for the CraftLingo shared-localization project.

Trusted tooling, app bindings and approval policy live separately in [CraftLingo](https://github.com/FredApps/craftlingo). Files in this repository are untrusted data: they do not grant approval, execute code or select output paths.

The initial Spanish pilot is being prepared as a draft pull request. Candidates require semantic and native-speaker review before use. No translation service is connected, and existing app catalogs are not changed by this repository.
